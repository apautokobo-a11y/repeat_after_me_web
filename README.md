# Repeat after me 教室(Web版)

![version](https://img.shields.io/badge/version-1.2-f25284) ![platform](https://img.shields.io/badge/platform-ブラウザ-465068) ![install](https://img.shields.io/badge/インストール-不要-2f6fed)

先生オウムが「Repeat after me」と言い、黒板に書かれた言葉を生徒のオウム4羽が復唱する、日本語教室のアニメーションです。
「ち◯◯ん」ボタンを押すと、生徒の誰かが余計なことを言い出してフィーバータイムに突入します。

HTMLファイル1つだけで動きます。インストールもサーバーも不要です。

| 項目 | 内容 |
|---|---|
| バージョン | 1.2(2026-11-11) |
| ファイル | `repeat_after_me_web_v1.2.html` |
| 動作環境 | PC・スマホのブラウザ(Chrome / Edge / Safari / Firefox の現行版) |
| 元になった版 | Python版 `repeat_after_me_v1.1.py` のブラウザ移植 |

## 遊び方

1. `repeat_after_me_web_v1.2.html` をダウンロードして、ブラウザで開く
2. 「▶ 授業をはじめる」を押す(音と読み上げが出ます)
3. 授業が自動で進むので、好きなタイミングで「ち◯◯ん」を押す

GitHub Pages を有効にすれば、次のURLでそのまま公開できます。

```
https://<ユーザー名>.github.io/<リポジトリ名>/repeat_after_me_web_v1.2.html
```

## 授業の流れ

1. 先生「Next is Japanese lesson」「are you ready?」→ 生徒「ok」
2. 先生「Repeat after me」→ 黒板に言葉が書かれる
3. 先生が読み、生徒4羽が復唱する
4. 先生「It means ○○」(英語の意味)→ 生徒「ok」
5. 先生「next」で次の言葉へ。以降くり返し

## ち◯◯ん(フィーバータイム)

ボタンか Space キーを押すと、生徒の誰か1羽が言葉を「ち」で切って「〜ち」+「んちん」と言い出します。

- 例: 桜木町(さくらぎちょう)→ さくらぎちんちん
- そのままフィーバータイムに入り、全員が踊ってBGMが流れます
- ネタは「ち◯◯ん の言葉」リストか、いま黒板に出ている言葉から選ばれます
- 「ちんちん」の前の最低文字数を設定できます(初期値 3。「こんに」ちんちん は使う、「はま」ちんちん は使わない)

## 操作

| 操作 | ボタン | キー |
|---|---|---|
| フィーバー開始 | ち◯◯ん | Space / Enter |
| 一時停止・再開 | 一時停止 | P |
| 次の授業で黒板に書く言葉を入力 | 黒板に書く | B |
| 言葉リストと設定を開く | 言葉リスト | E |
| 音声のON/OFF | 音声 ON | V |
| 音量(10%刻み) | － / ＋ | ↓ / ↑ |
| 全画面 | 全画面 | F |

スマホは横向きにすると大きく表示され、ボタンが右側に縦並びになります。

## 言葉リストの編集

「言葉リスト」から、授業の言葉とネタの言葉を自由に書き換えられます。1行に1語、カンマ区切りです。

**黒板に書く言葉(授業)** — `言葉,意味(英語),よみ`

```
こんにちは,hello
日曜日,Sunday,にちようび
```

**ち◯◯ん の言葉** — `言葉,よみ`(かなだけなら よみ は省略可)

```
桜木町,さくらぎちょう
サンドイッチ
```

### 設定項目

| 項目 | 範囲 | 初期値 |
|---|---|---|
| 授業の順番 | 順番 / ランダム | 順番 |
| フィーバー秒数 | 2〜30秒 | 6秒 |
| 黒板の言葉をネタにする確率 | 0〜100% | 50% |
| 「ちんちん」の前の最低文字数 | 1〜8文字 | 3文字 |

設定はブラウザ(localStorage)に保存されます。別のブラウザや端末には引き継がれないので、移したいときは「設定を書き出す」で `repeat_after_me_settings.json` を保存し、「設定を読み込む」で取り込んでください。このJSONは Python版の設定ファイルと同じ形式です。

## 音声について

| 声 | 方式 |
|---|---|
| 生徒の復唱(初期リストの12語)と「OK」 | あらかじめ作った4人の合唱音声を再生 |
| 先生のせりふ | ブラウザの読み上げ(Web Speech API) |
| 追加した言葉の復唱、ち◯◯ん | ブラウザの読み上げ(1人の声) |

- ブラウザの読み上げは、端末に入っている音声を使います。日本語の声が入っていない端末では読み上げが出ないか、発音が不自然になります
- 読み上げは同時に1つしか鳴らせないため、合唱音声のない言葉は1人の声で読みます
- 音が出ないときは、端末の消音(マナーモード)と、画面の「音声 ON」「音量」を確認してください

## しくみ

- 描画: Canvas(1280×720 を画面に合わせて拡大縮小)
- 音: Web Audio API(合唱・BGM)、Web Speech API(読み上げ)
- 素材: オウム・黒板・角帽の画像(WebP)とBGM・合唱音声(MP3)を、すべて Base64 でHTMLに埋め込み
- 外部への通信なし。オフラインでも動きます(ファイルサイズ 約1.3MB)

## クレジット
